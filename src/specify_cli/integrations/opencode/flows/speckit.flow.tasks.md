## Flow Step: Tasks

This is the **tasks** step of the Spec Kit sequential flow.

Run the full tasks command to break down the plan into implementation tasks.

## Instructions

1. Check if `plan.md` exists (required prerequisite)
2. If not, redirect to the plan step
3. If yes, run the full `/speckit.tasks` command
4. Tasks will be written to `tasks.md`

## Completion

After this step completes, the flow will automatically proceed to the **implement** step.

## Artifact

- `tasks.md` — Implementation task breakdown
