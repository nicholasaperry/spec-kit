## Flow Step: Plan

This is the **plan** step of the Spec Kit sequential flow.

Run the full plan command to create the technical implementation plan.

## Instructions

1. Check if `spec.md` exists (required prerequisite)
2. If not, redirect to the specify step
3. If yes, run the full `/speckit.plan` command
4. The plan will be written to `plan.md`

## Completion

After this step completes, the flow will automatically proceed to the **tasks** step.

## Artifact

- `plan.md` — Technical implementation plan
