## Flow Step: Specify

This is the **specify** step of the Spec Kit sequential flow.

Run the full specify command to create or update the feature specification.

## Instructions

1. Read the user's feature description
2. Check if `spec.md` already exists
3. If it exists, ask if the user wants to update it or keep it
4. If updating, run the full `/speckit.specify` command
5. If creating, run the full `/speckit.specify` command

## Completion

After this step completes, the flow will automatically proceed to the **plan** step.

## Artifact

- `spec.md` — Feature specification
